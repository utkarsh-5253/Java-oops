# Bank Account Management System

This is a simple Java OOP assignment to manage two bank accounts.

## Concepts Used
- Classes and Objects
- Parameterized Constructor
- Methods
- Separate objects with independent balances

## Features
- Deposit money
- Withdraw money
- Check current balance
- Display account details
- Check for insufficient balance

## Files
- `BankAccount.java` - Contains the BankAccount class and its methods.
- `Main.java` - Creates two accounts and performs the operations.

## How to Run

Open the terminal in this folder and run:

```bash
javac BankAccount.java Main.java
java Main
```
