# Java OOP Assignments

This repository contains my Java programming and Object-Oriented Programming (OOP) assignments and practice programs.

## Projects

### Bank Account Management System

A beginner-friendly Java project that demonstrates basic OOP concepts by creating and managing two bank accounts.

**Features:**
- Create bank accounts using a constructor
- Deposit money
- Withdraw money
- Check account balance
- Display account details
- Handle invalid amounts and insufficient balance

**Concepts used:**
- Classes and objects
- Parameterized constructors
- Methods
- Object-specific data and balances

**Project files:**
- `BankAccountManagement/BankAccount.java` – Contains the `BankAccount` class and its methods.
- `BankAccountManagement/Main.java` – Creates two accounts and demonstrates the operations.
- `BankAccountManagement/README.md` – Project-specific instructions.

## Run the Bank Account Management System

Open the terminal inside the `BankAccountManagement` folder and run:

```bash
javac BankAccount.java Main.java
java Main
```
